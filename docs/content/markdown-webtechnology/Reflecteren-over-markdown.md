> Je hebt de afgelopen lessen geleerd wat Markdown is, waarom het gebruikt wordt en hoe je er zelf digitale inhoud mee kunt maken.

Tijdens deze opdracht gaan we een markdown **tekst document** maken met: [https://dillinger.io/](https://dillinger.io/)

Reflecteer over wat je leerde tijdens deze Markdown lessen en beantwoord deze vragen in het markdown document.  
**Vergeet niet om voldoende markdown codes te gebruiken.**

# Reflectie vragen

## Wat is Markdown

1. Leg in je eigen woorden uit wat Markdown is.
2. Wat is volgens jou het **belangrijkste** doel van Markdown?
3. Wat is voor jou het belangrijkste **voordeel** aan Markdown?
4. Wat is voor jou het belangrijkste **nadeel** aan Markdown?

## To Markdown or not?

5. Zou je Markdown opnieuw gebruiken voor een document of presentatie? **Waarom wel/niet?**
6. Wat vind je handiger: opmaak via knoppen zoals in Word/Documenten/PowerPoint/Presentaties of opmaak schrijven via Markdown-syntax?
7. Geef Markdown een score van 1 tot 10.
8. Geef Word een score van 1 tot 10.

## Kijk kritisch naar je eigen werk

1. Wat vind je het beste gelukt aan je presentatie?
2. Wat zou je bij een volgende presentatie anders aanpakken?
