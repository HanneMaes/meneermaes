> Maak een presentatie over jezelf door meerdere digitale tools to combineren.

# Wat kan je allemaal vertellen

- **Wie** ben je?
- **Waar** woon je?
- **Hoe** kom je naar school?
- Wat zijn je **hobbies**?
- Wat heb je deze **vakantie** allemaal gedaan?
- Wat **wil je graag leren** tijdens deze lessen?

# Opdracht

## Stap 1: Ontdek Google Earth

Je gaat **zelfstandig** Google Earth verkennen. Het is de bedoeling dat je:
- Uitzoekt hoe Google Earth werkt.
- Een **presentatie** maakt waarin je van plek naar plek vliegt.
- Zo veel mogelijk functies gebruikt (bijvoorbeeld routes tekenen, dia’s toevoegen, markeringen maken…).

**Eindresultaat:** een Google Earth presentatie waarin je laat zien dat je de mogelijkheden van het programma begrijpt en creatief toepast.

**Tips:**
- **Maak gebruik van zo veel mogelijk verschillende elementen**
![earth.gif](earth.gif)
- Google Earth presentaties kan je **niet uploaden** maar wel **delen**.
Deel je project met **hanne.maes@bazandpoort.be**.

## Stap 2: Maak gebruik van andere tools om je presentatie aan te vullen

Maak gebruik van de tools uit de **lijst** om je presentatie vorm te geven.

Wil je een tool gebruiken die **niet in deze lijst** staat, **vraag het dan na aan de leerkracht**.

> Wanneer je een foto/video/… gebruikt in je presentatie die je zelf gemaakt hebt dan vermeld je erbij welke tool je gebruikt hebt.**

### StoryboardThat

Hiermee kan je **strips** maken.
- Link naar de tool: [https://www.storyboardthat.com/](https://www.storyboardthat.com/)

### Giphy Create

Hiermee kan je **gifs** maken.
- Link naar de tool: [https://giphy.com/create/gifmaker](https://giphy.com/create/gifmaker)

### Canva

Hiermee kan je **posters, ontwerpen en videos** maken.
- Link naar de tool: [https://www.canva.com/nl_nl/](https://www.canva.com/nl_nl/)

### Photo Collage

Hiermee kan je **collages** maken.
- Link naar de tool: [https://www.photocollage.com/](https://www.photocollage.com/)

### Gravit Designer

Hiermee kan je **tekeningen** maken.
- Link naar de tool: [https://app.corelvector.com/](https://app.corelvector.com/)

### PIXLR X

Hiermee kan je een **foto's bewerken** maken.
- Link naar de tool: [https://pixlr.com/nl/x](https://pixlr.com/nl/x)

### Timeline JS

Hiermee kan je een **interactieve tijdlijn** maken.
- Link naar de tool: [http://timeline.knightlab.com/](http://timeline.knightlab.com/)
- Link naar de cursus: [Timeline JS](https://app.notion.com/p/Timeline-JS-70767e295d7a438aae68238d2a1abc82?pvs=21)

### TinkerCAD

Hiermee kan je een **3D tekeningen** maken.
- Link naar de tool: [https://www.tinkercad.com/](https://www.tinkercad.com/)
- Link naar de cursus: [TinkerCad CodeBlocks](https://app.notion.com/p/TinkerCad-CodeBlocks-49d41492409b42afafa84ed086035eee?pvs=21)
